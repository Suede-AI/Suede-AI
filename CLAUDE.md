The public profile and docs repo for Suede AI (Suede Labs AI).

[docs/positioning.md](docs/positioning.md) is the single source of truth. Every README section, doc, idea and piece of copy must match it:

- Lead with **SEO, AEO and GEO**, **AI integration** (Suede AI Agent Studio), and **FDE (forward deployed engineering)**. Agent commerce (x402 and ACP) supports these four.
- Creator ownership, programmable IP, music products and the SUEDE token are portfolio and history, not the lead.
- Keep entity names consistent: Suede AI / Suede Labs AI, founded and led by Jason Colapietro, also known publicly as Jay Colapietro and Johnny Suede.
- Don't make up results, client names or metrics.

If the positioning changes, update `docs/positioning.md` first, then bring the README and the other docs in line.
